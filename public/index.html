设置

密钥只保存在本机浏览器（localStorage），经本地服务转发给 DeepSeek，不经过任何第三方。 也可以在启动服务前设置环境变量 DEEPSEEK_API_KEY。

技术栈

  • 前端：原生 HTML / CSS / JavaScript 单页，无框架、无构建步骤
  • 后端：Node.js 原生 http 模块（零 npm 依赖），负责静态托管与 DeepSeek 代理
  • 模型：deepseek-chat，JSON 模式输出，temperature 0.1
  • 日程类型：时点类（某天某时）与时段类（连续多天，体现在周视图「全天」栏）
  • 存储：浏览器 localStorage
